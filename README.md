## Sobre mí 🚀
**Data Engineer** y **Arquitecto de Software** con más de **8 años de trayectoria** construyendo plataformas de datos y aplicaciones críticas de alto rendimiento. Me especializo en **arquitecturas de datos modernas on-premise, híbridas y cloud**: en **Google Cloud** (BigQuery como Data Warehouse central, arquitectura Medallion, dbt, pipelines **ETL/ELT** y **CDC**) y en escenarios híbridos (migraciones **Oracle → PostgreSQL/RDS en AWS con Talend**), consolidando fuentes heterogéneas en una **única fuente de verdad** en producción.

Complemento el dato con desarrollo **end-to-end** (Python/FastAPI, Node.js, Next.js) bajo **Clean Architecture**, pruebas automatizadas e integración práctica de **Inteligencia Artificial**. Actúo como **enlace estratégico** entre las necesidades de negocio y la implementación técnica, con foco creciente en **seguridad y gobierno de datos**: clasificación de datos sensibles, **Zero-Trust** y cumplimiento normativo (Ley 1581 / HL7-FHIR).

🎓 **Educación:** Ingeniería en Software.

### Proyectos Destacados 🛠️
- 🐾 **[PetDiagnos](https://www.petdiagnos.com)** — Plataforma SaaS de Gestión Veterinaria y Diagnóstico Asistido por IA
  - **Clean Architecture & Monorepo:** Sistema desacoplado (Next.js 15 App Router, Express/Node.js, FastAPI, PostgreSQL 16/Prisma, Redis 7) gestionado con Turborepo.
  - **IA Diagnóstica No-Bloqueante:** Ensemble de Machine Learning (*VotingClassifier*: Decision Tree, Random Forest, SVC) con patrón *Circuit Breaker* (Opossum) y reintento/fallback que garantiza la operatividad médica continua.
  - **Gobernanza & Ley 1581:** Sistema Zero-Trust B2B con invitaciones JWT, RBAC granular (4 roles), trazabilidad por `X-Trace-Id`, audit logs *append-only* y pipeline de anonimización para reentrenamiento de IA.
  - **Ingeniería de Calidad:** Cobertura de +280 tests automatizados (unitarios e integración con Vitest/Supertest), versionado optimista de historias clínicas y generación distribuida de PDFs.
- 🔍 **[Scavengr](https://github.com/JasRockr/Scavengr)** — Herramienta CLI en Python (Clean Architecture) para **gobierno y clasificación de datos**: extracción, validación y documentación de esquemas de BD con **clasificación automática de sensibilidad** (Crítico/Alto/Medio/Bajo), diccionarios de datos y reportes de calidad. Soporta PostgreSQL, MySQL y SQL Server; enfocada a auditoría, cumplimiento (Ley 1581) y data governance.
- 🧰 **[Airbyte Local Toolkit](https://github.com/JasRockr/airbyte-local-toolkit)** — Utilidades open-source (Bash/Docker) para desplegar, gestionar y automatizar instancias de ingesta de datos (CDC) con Airbyte en local, acelerando las pruebas de conectores.
