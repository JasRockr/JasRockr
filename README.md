## Sobre mí 🚀

Ingeniero de Software y Profesional de TI con más de **8 años de trayectoria**. Especializado en el diseño de soluciones end-to-end bajo **Clean Architecture**, integración de APIs REST complejas, pruebas automatizadas y pipelines de datos.

Me destaco por actuar como **enlace estratégico** entre las necesidades de negocio y la implementación técnica, construyendo plataformas escalables que integran herramientas de **Inteligencia Artificial**, seguridad **Zero-Trust** y cumplimiento normativo (Ley 1581 / HL7-FHIR).

### Proyectos Destacados 🛠️

- 🐾 **[PetDiagnos](https://www.petdiagnos.com)** — Plataforma SaaS de Gestión Veterinaria y Diagnóstico Asistido por IA
  - **Clean Architecture & Monorepo:** Sistema desacoplado (Next.js 15 App Router, Express/Node.js, FastAPI, PostgreSQL 16/Prisma, Redis 7) gestionado con Turborepo.
  - **IA Diagnóstica No-Bloqueante:** Ensemble de Machine Learning (*VotingClassifier*: Decision Tree, Random Forest, SVC) con patrón *Circuit Breaker* (Opossum) y reintento/fallback que garantiza la operatividad médica continua.
  - **Gobernanza & Ley 1581:** Sistema Zero-Trust B2B con invitaciones JWT, RBAC granular (4 roles), trazabilidad por `X-Trace-Id`, audit logs *append-only* y pipeline de anonimización para reentrenamiento de IA.
  - **Ingeniería de Calidad:** Cobertura de +280 tests automatizados (unitarios e integración con Vitest/Supertest), versionado optimista de historias clínicas y generación distribuida de PDFs.
- 🧰 **[Airbyte Local Toolkit](https://github.com/JasRockr/airbyte-local-toolkit)** — Utilidades open-source (Bash/Docker) para simplificar el despliegue local y testing de instancias de ingesta de datos con Airbyte.
- 🔍 **[Scavengr](https://github.com/JasRockr/Scavengr)** — Herramienta CLI automatizada en Python para auditoría y recolección de metadatos estructurales a gran escala.
